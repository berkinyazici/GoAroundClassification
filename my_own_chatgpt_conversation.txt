1. Arkadaşın ne yapmaya çalışmış?
Yapılacak ödevin konusu şu:
Go-Around Classification Using ADS-B and METAR Data
Amaç: Her iniş örneği için go-around / missed approach olur mu olmaz mı diye tahmin yapan bir binary classification / Pattern Recognition projesi geliştirmek.
Yani hedef değişken:

y = 1 → go-around
y = 0 → normal landing

Modelin kullanacağı veri tipi:

ADS-B türevi landing bilgileri
+ airport/runway bilgileri
+ aircraft bilgileri
+ METAR weather bilgileri

Önemli karar şu: Proje raw ADS-B trajectory reconstruction olarak yapılmayacak. Yani altitude/position time-series çıkarma, trajectory sequence modeling gibi ağır işler MVP’ye dahil değil. Bunun yerine go_arounds_augmented.csv.gz içindeki hazır tabular veriyle başlanacak. Bu karar doğru, çünkü dönem projesi için daha gerçekçi ve yetiştirilebilir.

5. Devam için en mantıklı sıra
Senin devam etmen gereken sıra bence şu:
Aşama 1 — Projenin gerçekten kurulu olup olmadığını doğrula
Önce Python ortamı:

python3.11 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
pip install -e .

Paket import testi:

python -c "import sklearn, fastapi, lightgbm, polars; print('setup ok')"

Aşama 2 — Dataset doğrulama scriptini çalıştır
Eğer dosya varsa:

python src/data/verify_local_data.py

Eğer bu dosya yoksa, ilk sen bunu yazdırmalısın. Bu dosyanın görevi sadece şunu kontrol etmek:

data/raw/go_arounds_augmented.csv.gz var mı?
data/raw/go_arounds_agg.csv.gz var mı?
data/raw/validation_table.xlsx var mı?

Aşama 3 — Raw veriyi Parquet’e çevir

7. Kritik uyarılar
Bu projede accuracy’ye güvenmeyin. Go-around nadir bir olay olduğu için accuracy çok yüksek görünse bile model kötü olabilir. Ana metrikler şunlar olmalı:

PR-AUC
Recall
Precision
F1-score
ROC-AUC
Confusion matrix

Ayrıca rapor için model karşılaştırması önemli. Sadece LightGBM koyarsanız proje daha “engineering demo” gibi görünür. Pattern Recognition dersi için şu karşılaştırma daha iyi olur:

LDA
Logistic Regression
Random Forest veya LightGBM
MLP

Ek olarak context_only ve context_metar karşılaştırması çok iyi olur:

Context only:
airport, runway, aircraft, time, runway features

Context + METAR:
context features + wind, visibility, temperature, pressure, weather fields

Bu sayede “hava durumu bilgisi modele gerçekten katkı sağladı mı?” sorusuna cevap verebilirsiniz.
